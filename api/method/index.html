    abfml.core.model¶

    FieldModel(type_map, cutoff, neighbor) ¶

    Bases: Module, ABC

    Abstract base class for machine learning force field models.

    FieldModel provides a standardized interface for implementing custom force field models within the ABFML framework. It handles the automatic computation of forces and virial tensors through automatic differentiation, allowing developers to focus on implementing the energy calculation logic.

    The class manages the complete physics pipeline: - Neighbor list processing - Energy computation (via the abstract field method) - Automatic force derivation using PyTorch autograd - Virial tensor calculation

    Subclasses must implement the field method to define the specific energy calculation for their force field model.

    Attributes¶

    • type_map : List[int] Mapping of atomic species to model indices. Each unique element type should have a corresponding integer in this list.

    • neighbor : Union[Dict[int, int], int] Maximum number of neighbors per atom. Can be either:

      • int: Global maximum for all atom types
      • Dict[int, int]: Type-specific maximums {type_id: max_neighbors}

    • cutoff : float Cutoff radius (in Angstroms) for neighbor search. Atoms beyond this distance are not considered neighbors.

    field(element_map, central_atoms, neighbor_indices, neighbor_types, neighbor_vectors, n_ghost) ¶

    Compute atomic energies and optionally forces for the force field model.

    This abstract method must be implemented by all subclasses. It defines the core physics of your force field - how atomic environments are converted into energies (and optionally forces/virials).

    Parameters¶

    element_map : torch.Tensor Atomic numbers for each atom, shape [batch_size, n_atoms]. Use this to apply element-specific parameters in your model.

    torch.Tensor

    Type indices (not atomic numbers) for central atoms, shape [batch_size, n_atoms]. Indices into self.type_map. Use for type-dependent calculations.

    torch.Tensor

    Neighbor atom indices, shape [batch_size, n_atoms, max_neighbors]. Value -1 indicates padding (no real neighbor). Use with torch.gather to collect neighbor properties.

    torch.Tensor

    Neighbor type indices, shape [batch_size, n_atoms, max_neighbors]. Corresponds to neighbor_indices, giving type of each neighbor.

    torch.Tensor

    Relative positions, shape [batch_size, n_atoms, max_neighbors, 4]. Format: [distance, dx, dy, dz] - distance: ||r_j - r_i|| in Angstroms - dx, dy, dz: components of r_j - r_i vector Use distance for radial functions, components for angular terms.

    int

    Number of ghost atoms (periodic images) in the system. Usually can be ignored unless doing specialized handling.

    Returns¶

    Dict[str, torch.Tensor] Dictionary with the following keys:

    **Required**:
- 'Etot' : torch.Tensor, shape [batch_size, 1]
    Total energy for each configuration in the batch.
    Must be provided and have correct shape.

- 'Ei' : torch.Tensor, shape [batch_size, n_atoms, 1]
    Per-atom energy contributions. Should sum to Etot.
    Must be provided and have correct shape.

**Optional** (provide only if computing analytically):

- 'Force' : torch.Tensor, shape [batch_size, n_atoms, 3]
    Atomic forces F = -dE/dr in Cartesian coordinates.
    If not provided, computed automatically via autograd.

- 'virial' : torch.Tensor, shape [batch_size, 3, 3]
    Virial stress tensor. Only relevant if providing Force.

- 'atomic_virial' : torch.Tensor, shape [batch_size, n_atoms, 9]
    Per-atom virial contributions (flattened 3x3 tensors).

    """
    Compute atomic energies and optionally forces for the force field model.

    This abstract method must be implemented by all subclasses. It defines the
    core physics of your force field - how atomic environments are converted
    into energies (and optionally forces/virials).

    Parameters
    ----------
    element_map : torch.Tensor
        Atomic numbers for each atom, shape [batch_size, n_atoms].
        Use this to apply element-specific parameters in your model.

    central_atoms : torch.Tensor
        Type indices (not atomic numbers) for central atoms, shape [batch_size, n_atoms].
        Indices into self.type_map. Use for type-dependent calculations.

    neighbor_indices : torch.Tensor
        Neighbor atom indices, shape [batch_size, n_atoms, max_neighbors].
        Value -1 indicates padding (no real neighbor). Use with torch.gather
        to collect neighbor properties.

    neighbor_types : torch.Tensor
        Neighbor type indices, shape [batch_size, n_atoms, max_neighbors].
        Corresponds to neighbor_indices, giving type of each neighbor.

    neighbor_vectors : torch.Tensor
        Relative positions, shape [batch_size, n_atoms, max_neighbors, 4].
        Format: [distance, dx, dy, dz]
        - distance: ||r_j - r_i|| in Angstroms
        - dx, dy, dz: components of r_j - r_i vector
        Use distance for radial functions, components for angular terms.

    n_ghost : int
        Number of ghost atoms (periodic images) in the system.
        Usually can be ignored unless doing specialized handling.

    Returns
    -------
    Dict[str, torch.Tensor]
        Dictionary with the following keys:

        **Required**:
        - 'Etot' : torch.Tensor, shape [batch_size, 1]
            Total energy for each configuration in the batch.
            Must be provided and have correct shape.

        - 'Ei' : torch.Tensor, shape [batch_size, n_atoms, 1]
            Per-atom energy contributions. Should sum to Etot.
            Must be provided and have correct shape.

        **Optional** (provide only if computing analytically):

        - 'Force' : torch.Tensor, shape [batch_size, n_atoms, 3]
            Atomic forces F = -dE/dr in Cartesian coordinates.
            If not provided, computed automatically via autograd.

        - 'virial' : torch.Tensor, shape [batch_size, 3, 3]
            Virial stress tensor. Only relevant if providing Force.

        - 'atomic_virial' : torch.Tensor, shape [batch_size, n_atoms, 9]
            Per-atom virial contributions (flattened 3x3 tensors).
    """
    return {'Etot': torch.tensor([0.0])}

        self.user_defined = self.UserDefined(input_dict["model_setting"])

    else:
        raise Exception(f"Undefined keyword: , Please read the manual!")

    def derive_mechanics(
    grad_Ei: torch.Tensor,
    neighbor_vectors: torch.Tensor,
    neighbor_indices: torch.Tensor,
    n_ghost: int
) -> Tuple[torch.Tensor, torch.Tensor, torch.Tensor]:
    batch, n_atoms, max_neighbors = neighbor_indices.shape
    dtype, device = neighbor_vectors.dtype, neighbor_vectors.device

    # Initialize force and per-atom virial tensors
    force = torch.zeros(batch, n_atoms + n_ghost, 3, dtype=dtype, device=device)
    force[:, :n_atoms, :] = grad_Ei.sum(dim=-2)  # Direct contribution from central atoms

    atomic_virial = torch.zeros(batch, n_atoms + n_ghost, 9, dtype=dtype, device=device)

    # Extract relative position vectors (exclude norm)
    rel_pos = neighbor_vectors[..., 1:]  # Shape: [batch, n_atoms, max_neighbors, 3]

    # Compute local virial contributions via outer product of dr and dE
    local_virials = torch.matmul(rel_pos.unsqueeze(-1), -1 * grad_Ei.unsqueeze(-2)).reshape(batch, n_atoms, max_neighbors, 9)

    # Replace invalid neighbor indices (-1) with 0
    neighbor_indices[neighbor_indices == -1] = 0

    for b in range(batch):
        # Flatten indices and contribution values
        neighbor_idx_b = neighbor_indices[b].view(-1).to(torch.int64)

        # Force scatter-add
        force_contrib_b = -1 * grad_Ei[b].view(-1, 3)
        index_f = neighbor_idx_b.unsqueeze(-1).expand(-1, 3)
        force[b] = force[b].scatter_add(0, index_f, force_contrib_b)

        # Virial scatter-add
        virial_contrib_b = local_virials[b].view(-1, 9)
        index_v = neighbor_idx_b.unsqueeze(-1).expand(-1, 9)
        atomic_virial[b] = atomic_virial[b].scatter_add(0, index_v, virial_contrib_b)

    # Compute total virial by summing over all atoms
    virial = atomic_virial.sum(dim=1)

    return force, virial, atomic_virial
